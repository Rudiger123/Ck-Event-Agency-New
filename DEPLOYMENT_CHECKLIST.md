# 📋 Deployment Checklist

## ✅ Pre-Production Tasks

### 1. **Database & Migrations**
- [ ] All migrations have been run: `php artisan migrate --force`
- [ ] Database seeding completed (if needed): `php artisan db:seed`
- [ ] Foreign keys are defined correctly
- [ ] Indexes are in place for performance

### 2. **Dependencies & Autoloader**
- [ ] Composer dependencies installed: `composer install --no-dev`
- [ ] Autoloader regenerated: `composer dump-autoload -o`
- [ ] All helper files are loaded (check `vendor/composer/autoload_files.php`)
- [ ] No composer conflicts or warnings

### 3. **Configuration**
- [ ] `.env` file configured with production values:
  - `APP_ENV=production`
  - `APP_DEBUG=false` (CRITICAL - never true in production)
  - `ADMIN_EMAIL` set to Cynthia's email
  - `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD` configured
  - `DATABASE_URL` or database credentials set
  - `QUEUE_CONNECTION=database` (for Hostinger or server)
  
- [ ] Configuration cached: `php artisan config:cache`
- [ ] Routes cached: `php artisan route:cache`
- [ ] Views cleared: `php artisan view:clear`

### 4. **SEO System**
- [ ] SeoService is registered as singleton in `AppServiceProvider.php`
- [ ] Helper function `renderSeoHead()` is loading: `php -r "require 'vendor/autoload.php'; echo function_exists('renderSeoHead') ? 'OK' : 'FAIL';"`
- [ ] SEO data configured in `config/app.php`:
  - `admin_email`
  - `phone`
  - `email`
  - `founding_date`
  - `address.*`
  - `social.*`
- [ ] Test homepage loads without errors: `curl https://yourdomain.com`
- [ ] Meta tags visible in page source (view-source)
- [ ] JSON-LD schema present on article/event pages

### 5. **Email System**
- [ ] SMTP credentials configured and tested
- [ ] Mail queue is operational: `php artisan queue:work --once`
- [ ] Observers are firing (Message, QuoteRequest, Comment)
- [ ] Admin email templates rendering correctly
- [ ] Try/catch blocks in place for mail failures

### 6. **Queue System (Hostinger)**
- [ ] Database queue driver configured: `QUEUE_CONNECTION=database`
- [ ] Queue tables migrated: `php artisan migrate`
- [ ] Cron job configured:
  ```bash
  * * * * * cd /home/username/public_html && php artisan queue:work --max-jobs=1000 --max-time=3600
  ```
- [ ] Cron job created 5 minutes ago to test
- [ ] Check `/tmp/cron.log` or Hostinger cron history

### 7. **Assets & Frontend**
- [ ] Assets compiled: `npm run build`
- [ ] CSS/JS minified
- [ ] Images optimized
- [ ] Favicon linked correctly
- [ ] Fonts loading from CDN

### 8. **Storage & File Uploads**
- [ ] Storage symlink created: `php artisan storage:link`
- [ ] Upload directory permissions set: `chmod 755 storage/app/public`
- [ ] Media library working for article/event images

### 9. **Security**
- [ ] `APP_KEY` generated: `php artisan key:generate`
- [ ] Session configuration secure (HTTPS only in production)
- [ ] CSRF protection enabled
- [ ] SQL injection prevention (all queries use Eloquent)
- [ ] `.env` file not accessible from web
- [ ] `/storage` and `/bootstrap` not in web root

### 10. **Monitoring & Logging**
- [ ] Log rotation configured: `config/logging.php`
- [ ] Error monitoring (check `storage/logs/laravel.log` regularly)
- [ ] Uptime monitoring configured (optional)
- [ ] Email alerts for critical errors

### 11. **Admin Panel (Filament)**
- [ ] Admin user created: `php artisan tinker` → `User::create([...])`
- [ ] Filament assets published: `php artisan filament:install`
- [ ] Admin dashboard accessible at `/admin`
- [ ] Form validations working
- [ ] File uploads working in admin

### 12. **Search Engines (SEO)**
- [ ] Google Search Console configured
- [ ] Sitemap submitted to Google
- [ ] Robots.txt configured properly
- [ ] XML sitemap generated (if not auto-generated by Laravel)
- [ ] Google Analytics tracking code added
- [ ] Structured data tested: https://search.google.com/structured-data/testing-tool

### 13. **Testing**
- [ ] Homepage loads: ✓ `http://localhost:8000`
- [ ] Blog page loads and displays articles
- [ ] Article detail page shows SEO meta tags
- [ ] Portfolio/Events page loads
- [ ] Event detail page shows SEO meta tags
- [ ] Contact form submits and triggers observer
- [ ] Newsletter subscription works
- [ ] Quote request form works and sends email
- [ ] Admin panel is accessible and functional

### 14. **Production Cache Clearing (Final Step)**
```bash
# Run only AFTER everything is configured and tested
php artisan config:clear
php artisan cache:clear
php artisan view:clear

# Then regenerate caches
php artisan config:cache
php artisan view:cache
php artisan route:cache

# Finally, restart queue worker on Hostinger
killall php  # (if possible)
# Or wait for next cron execution
```

## 🚀 Deployment Steps (for Hostinger)

1. **SSH into Hostinger**
   ```bash
   ssh user@hostinger-server
   cd /home/username/public_html
   ```

2. **Pull latest code from Git** (if using version control)
   ```bash
   git pull origin main
   ```

3. **Install dependencies**
   ```bash
   composer install --no-dev --optimize-autoloader
   ```

4. **Run migrations**
   ```bash
   php artisan migrate --force
   ```

5. **Clear and regenerate caches**
   ```bash
   php artisan config:clear && php artisan cache:clear
   php artisan config:cache && php artisan view:cache
   ```

6. **Create storage symlink**
   ```bash
   php artisan storage:link
   ```

7. **Build frontend assets**
   ```bash
   npm install && npm run build
   ```

8. **Verify everything works**
   ```bash
   curl https://yourdomain.com
   ```

## ⚠️ Common Issues

### Queue Worker Not Processing Jobs
- ✓ **Solution**: Restart queue with `kill` or check cron log
- ✓ **Verify** with: `php artisan queue:work --once`

### Meta Tags Not Showing
- ✓ **Solution**: Run `composer dump-autoload` and `php artisan cache:clear`
- ✓ **Verify** with: `php -r "require 'vendor/autoload.php'; echo function_exists('renderSeoHead') ? 'OK' : 'FAIL';"`

### Mail Not Sending
- ✓ **Solution**: Check `.env` SMTP credentials
- ✓ **Solution**: Check `config/mail.php` markdown section
- ✓ **Solution**: Run `php artisan queue:work --once` to process queued emails

### Images Not Displaying
- ✓ **Solution**: Ensure `storage/app/public` has correct permissions
- ✓ **Solution**: Verify storage symlink exists
